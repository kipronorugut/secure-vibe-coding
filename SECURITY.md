# Security policy

**Do not submit live credentials, private source code, or exploitable production details in public issues.**

For a potential security weakness in this toolkit, contact the maintainer privately through GitHub's private vulnerability reporting feature, if enabled, or through a private professional channel published by the maintainer. No response SLA is promised.

Review any skill before running it. This repository is instruction-first and does not automatically execute scans or collect telemetry. No security audit or compliance certification is implied.
