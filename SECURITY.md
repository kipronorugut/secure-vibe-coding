# Security policy

**Do not submit live credentials, private source code, or exploitable production details in public issues.**

For a potential security weakness in this toolkit, contact the maintainer privately through GitHub's private vulnerability reporting feature, if enabled, or through a private professional channel published by the maintainer. No response SLA is promised.

Review any skill before running it. This repository is instruction-first and does not automatically execute scans or collect telemetry. One optional helper, `skills/cve-to-pr-remediation/scripts/inventory.sh`, runs only when you or your agent invoke it; it reads files, makes no network calls and modifies nothing. No security audit or compliance certification is implied.
